# Mnemosyne

SillyTavern 轻量剧情记忆扩展。只做一条主线:**自动记录剧情 → 折叠成长期记忆注入 → 隐藏已覆盖的旧楼层**,外加长聊天用的**补建历史**。

## 功能

- **自动记录**:新的一轮对话移出「最近 N 层」后,写成一条剧情记录,并顺带记下「必留点」——原话台词、物品、数字、称呼、约定、伏笔(默认关闭,在首页打开)。
- **补建历史**:长聊天一键补记旧楼层,多轮打包进一次请求;可停止、继续。空回复会自动重试;某一批被模型拒绝时会拆小重试,只跳过真正被拒的那一轮(不隐藏,主模型仍能看到原文),在首页列出,可一键重试。
- **长期记忆**:记录攒够阈值后折叠成五节——前情、人物与关系、当前状态、时间线、未结事项。前情先写忠实草稿,再参照原文的文风样本润色;润色稿若丢了人名、物品名等关键词,自动改用草稿。
- **前情分篇章**:每次折叠只为这批新记录写一篇前情,接在已有篇章之后,写好的篇章不再被改写,不会越压越短。篇章合计超过设置里的「前情上限」时,才把最早的两篇合并成一篇(本地核对关键词和篇幅,不过关就原样保留);越近的篇章保留越多细节。长期记忆页里每篇带楼号,手动编辑时每篇以 `### #楼号` 开头。
- **召回旧记录**:折叠后札记保留原始记录和几个召回关键词。最近几层提到某段旧记录的关键词时,把那段原文带回来(「相关的旧记录」一节,最多几条可在设置里调),纯本地关键词匹配,不多调模型;太常见的词自动忽略。已有聊天只对更新之后折叠的记录生效,想整本都能召回,需要「清除数据」后重新补建。
- **摘要来源**:每个聊天可选「自己写」(模型把每一轮写成记录)或「从楼层提取」——直接取 AI 楼里已有的摘要标签或折叠块,不花 token;取不到的轮仍由模型补记。点「检测」会列出最新一楼里出现的所有标签,点选即可;还可以指定一个标签,里面的每一行直接变成伏笔。
- **人物动线**:「人物与关系」每人一块——倾向、当前、来由(带楼号)。折叠时按固定的更新规则维护,单次事件不会被写成性格;来由里不存在的楼号会被自动去掉。注入时只带在场的和最近提到的人物。
- **现场快照与推测**:每条记录顺带写下当时的地点、时间、在场人物和悬念,注入时「当前状态」优先用最新的快照。锚点新增「推测」类别(怀疑、误会、未证实的猜测),常驻注入并标明未证实,被证实或证伪时撤下。
- **注入透明**:首页显示上次注入约多少 token、各部分占比;点开可看注入了哪些人物和锚点、哪些被筛掉以及原因。超过设置里的提醒线会标黄。
- **锚点**:必留点汇总成「锚点」,由扩展保管,不经润色改写;了结、过期或重复的条目在折叠时撤下(可在面板里恢复)。注入时伏笔与约定始终带上,其余只在最近几层提到时带上。只收跟主线(主要人物之间的关系、长期目标)有关的细节,单个事件里用完就丢的道具、数字、次要人物的话不收;事件结束后折叠时会把这类条目撤下(折叠材料里每条锚点带出处:哪几楼、哪条记录)。面板里按类别分组折叠;点「整理锚点」可以让模型一次性把已经了结的旧条目撤下,撤错了可以恢复,也可以用「撤销上一次折叠」整体撤回。
- **物品档案**:物品类锚点多带「来历」(原文写到的来由、外形、寓意,写记录时就取下,不经模型改写)和「现状」(折叠时维护:谁拿着、在哪、完好还是坏了);同一件东西被重复记录时合并成一条,key 可用「/」写别名。只在相关词出现在最近几层时才注入,平时不占 token。
- **版本与回退**:长期记忆保留最近几版,可连续撤销;删掉的楼层若已并入长期记忆,会自动回退到较早版本并重新整理。
- **隐藏旧楼层**:已被记录覆盖的楼层自动隐藏,不进提示词;原楼被编辑、swipe 或删除时,对应记录作废并取消隐藏;删楼后聊天变短,保留区内的楼层会自动恢复显示。「恢复全部隐藏」只恢复本扩展隐藏的楼层。
- **注入方式**:默认自动注入;也可以在设置里切到宏,用 `{{mnemosyne}}` 把记忆放在预设里任意位置。

## 安装

酒馆「扩展」→「安装扩展」,填入本仓库地址。打开方式:魔杖菜单里的 Mnemosyne,或右侧悬浮球。

## 模型

可跟随酒馆当前连接、指定 Connection Profile,或填写独立的 OpenAI 兼容 API(支持拉取模型列表)。

## 轻量设计

每层楼的指纹只算一次,每条消息只处理受影响的楼层和最近几层;所有改动合并成一次保存。1000 楼、200 条记录的聊天,单条消息的处理耗时在 1 毫秒量级。

从 0.1.x 升级时,已有的记录会原地迁移,不会清空。
