# Mnemosyne

SillyTavern 轻量剧情记忆扩展。只做一条主线:**自动记录剧情 → 折叠成长期记忆注入 → 隐藏已覆盖的旧楼层**,外加长聊天用的**补建历史**。

## 功能

- **自动记录**:新的一轮对话移出「最近 N 层」后,写成一条剧情记录(默认关闭,在首页打开)。
- **补建历史**:长聊天一键补记旧楼层,多轮打包进一次请求;可停止、继续,失败停在当前批。
- **长期记忆**:记录攒够阈值后折叠成四节——前情、人物与关系、时间线、未结事项。前情先写忠实草稿,再参照原文的文风样本润色。可编辑,可撤销到上一版。
- **隐藏旧楼层**:已被记录覆盖的楼层自动隐藏,不进提示词;原楼被编辑、swipe 或删除时,对应记录作废并取消隐藏。「恢复全部隐藏」只恢复本扩展隐藏的楼层。

## 安装

酒馆「扩展」→「安装扩展」,填入本仓库地址。打开方式:魔杖菜单里的 Mnemosyne,或右侧悬浮球。

## 模型

可跟随酒馆当前连接、指定 Connection Profile,或填写独立的 OpenAI 兼容 API(支持拉取模型列表)。

## 轻量设计

每层楼的指纹只算一次,每条消息只处理受影响的楼层;长期记忆只保留当前版与上一版;所有改动合并成一次保存。1000 楼、200 条记录的聊天,单条消息的处理耗时在 1 毫秒以内。
